🛠️ Dev / outils

GitHub Actions adopte les fichiers de verrouillage

C'est l'équivalent d'un package-lock.json pour la CI : un fichier .github/workflows/actions.lock enregistre le commit exact de chaque action utilisée, dépendances indirectes comprises. Si un mainteneur se fait pirater et redirige un tag vers du code malveillant, vos workflows ne suivent pas. L'extension gh actions-lock génère le fichier, Dependabot sait le mettre à jour, et les admins peuvent le rendre obligatoire. C'est en préversion publique, d'abord pour GitHub Enterprise Cloud.

Claude Code Review sort de la préversion

L'outil d'Anthropic qui relit automatiquement les pull requests GitHub est désormais ouvert aux offres Team et Enterprise. Les relectures sont environ trois fois plus rapides (6 à 10 minutes au lieu de 20), avec trois niveaux au choix : rapide, standard ou approfondi. Les remarques restent indicatives : l'outil ne bloque ni n'approuve aucune pull request. Chaque relecture est facturée à part, entre 15 et 25 $ environ selon la taille des modifications.
