Google adopte Pyrefly, le vérificateur de types Python de Meta

Fait rare entre rivaux : Google remplace son propre outil, Pytype, par Pyrefly, l'outil open source écrit en Rust par Meta, qui vérifie la cohérence des types dans le code Python. Résultat annoncé : des recompilations jusqu'à 98 % plus rapides et plus de 80 % de calcul économisé ; une vérification passe de 247 secondes à moins de 5. Pytype ne suivra plus les nouvelles versions de Python après la 3.12.
