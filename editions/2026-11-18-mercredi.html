🛠️ Dev / outils

Des scripts Optimizely piégés sur près de 180 sites

Le 16 novembre, du code malveillant (qui vole les numéros de carte bancaire et remplace les adresses de portefeuilles crypto) a été envoyé aux visiteurs de sites utilisant Optimizely, un outil de tests A/B très répandu. Les attaquants ont glissé leur code dans un champ JavaScript que chaque client peut modifier lui-même, et non dans l'infrastructure d'Optimizely. Le chercheur Scott Helme a compté 188 scripts infectés ; des noms comme Zoom, GitLab ou la BBC sont cités, mais les chiffres varient selon les sources. Optimizely n'avait pas encore réagi publiquement. La leçon pour les devs : même un script tiers « de confiance » peut servir de porte d'entrée.

🇨🇳 Chine

Washington ferme la porte des data centers étrangers à la Chine

La règle évoquée la semaine dernière est tombée lundi : il faut désormais une licence américaine pour livrer des puces IA avancées à tout centre de données, n'importe où dans le monde, qui peut fournir une puissance importante (l'équivalent d'environ 750 puces Nvidia H200) à des entreprises chinoises. Les exploitants concernés ont 90 jours pour se mettre en règle, et la Malaisie, Singapour, la Thaïlande, l'Indonésie et le Brésil sont particulièrement visés. Objectif : empêcher les labos chinois de louer à l'étranger les puces qu'ils ne peuvent pas acheter.
