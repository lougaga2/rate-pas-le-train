Faille critique sur Bifrost, une passerelle IA utilisée par de nombreux développeurs

Cette CVE (score 9,8/10) touche les versions du transport HTTP de Bifrost antérieures à 2.1.0 lorsque l'authentification de gestion est désactivée — ce qui est le réglage par défaut. Un attaquant non authentifié peut enregistrer un faux client MCP via une simple requête et exécuter des commandes arbitraires sur le serveur, avec accès aux clés d'API de tous les fournisseurs de modèles connectés. Le correctif est disponible en version 2.1.0.

Intrinsic (Alphabet) passe en open source le cœur de sa plateforme de robotique industrielle
