Claude Haiku 5.5 : le petit modèle d'Anthropic devient beaucoup plus fort et moins cher

Anthropic complète sa gamme 5.5 avec Haiku, son modèle le plus rapide et le moins cher, pensé pour les tâches à gros volume (résumés, tri, support client) et pour servir de « sous-agent » à Opus ou Sonnet. Windows 11 met les agents IA en cage : Microsoft Execution Containers disponible

Microsoft rend disponible MXC, qui permet de définir précisément les fichiers et réseaux auxquels un agent IA a accès, Windows faisant respecter ces limites pendant l'exécution (processus isolé, session Windows séparée, WSL…). Codex d'OpenAI, GitHub Copilot, Replit ou LM Studio le prennent déjà en charge, et Claude Code doit suivre. Un garde-fou bienvenu à l'heure où les agents manipulent nos machines.
